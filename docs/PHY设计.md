# COFDM v0.1 物理层详细设计

本文为v1固定长度基线。新增的1符号短头、1～2048字节变长载荷及IP分层方案见 [PHY v2设计](IP承载与可变长度帧设计.md)；v2需显式选择，两版本不自动互通。

日期：2026-09-23。指定硬件 Zynq-7020；载频、发射功率、天线、速度、时延目标尚未给定。先采用 SISO、突发短帧、固定 QPSK 1/2。以下区分已实现基线与后续设计，不能把规划参数当作实测指标。

本文描述默认 `baseline`。在相同空口格式下，现已新增可选的时延子空间信道估计和圆周导频跟踪实验，详见 [算法深化设计](算法深化设计.md)；不改变本文基线约定。

## 1. 参数与选择理由

| 项目 | 基线 | 理由/约束 |
|---|---|---|
| 复数采样率 | 15.36 MS/s | 用户指定；I/Q 各一路，不是两路相加 |
| FFT / CP | 256 / 32 | 用户指定；CP 占总符号 11.11% |
| 子载波间隔 | 60 kHz | Fs/N；由当前采样率和 FFT 点数确定 |
| 有效符号 / 总符号时长 | 16.667 / 18.75 μs | 总符号 288 个复数采样 |
| 有效载波 | -100…-1、+1…+100 | DC 空置，边缘保护；中心跨度约 12 MHz |
| 数据/导频 | 192 / 8 | 导频开销 4%，与 648 位 LDPC 的装帧精确匹配 |
| 导频位置 | ±13、±39、±65、±91 | 基线用于跟踪公共相位与相位斜率，不独立重建任意多径信道 |
| 调制/编码 | Gray QPSK，QC-LDPC 648/324 | 短码降低延迟和存储；高码长增益留待实测比较 |
| 训练 | STF + ZC LTF1 + ZC LTF2 | 粗频偏/定时 + 全带宽信道估计 |
| 中间训练 | 每 8 个数据符号后插入一个 | 27 数据符号共 3 个；间隔约 150–169 μs |
| 帧间保护 | 32 个零样本 | 仿真便于分帧；不是 TDD 射频开关保护时间承诺 |

12 MHz 是载波分配量级，并不是已满足某种频谱模板的占用带宽。实际 ACLR/OOB 需过采样、DAC/模拟滤波和 PA 模型验证。

## 2. 帧结构及精确开销

```text
STF(160)
LTF1(32+256) LTF2(32+256)
HEADER × 4(每个32+256，BPSK)
DATA × 8 MID
DATA × 8 MID
DATA × 8 MID
DATA × 3
GUARD(32)
```

- 有效帧：160 + (2 + 4 + 27 + 3)×288 = 10528 个样本。
- 帧槽：10560 个样本 = 687.5 μs。
- 载荷码字：16×648 = 10368 位，恰好填满 27×192×2 个数据位。
- LDPC 信息位：16×324 = 5184 位；扣除 CRC32 后为 5152 位 = 644 字节。
- 净速率：5152/687.5 μs = 7.493818 Mbit/s；未扣 ARQ、MAC 地址/序号、TDD、MAC 排队、停发时间。
- 若只看连续 QPSK 数据符号：192×2×1/2/18.75 μs = 10.24 Mbit/s。它不是最终帧净速率。

定长帧先确保 FPGA 地址与缓存清晰。可变长、跨帧码块聚合及短帧模式后续通过新 profile 引入，不隐式修改 v0.1。

## 3. 比特、载波与数值约定

1. 字节 MSB 优先，字段多字节按高字节优先；码字按系统信息位324 + 校验位324 输出。
2. MATLAB 未 fftshift 的频域索引 `mod(k,256)+1`；数据子载波按有符号 k 从小到大排列。
3. QPSK：第一位控制 I，第二位控制 Q；0 为正；X=((1-2bI)+j(1-2bQ))/sqrt(2)。BPSK 为 1-2b。
4. 浮点 TX 用 `sqrt(256)*ifft(X)`，RX 用 `fft(x)/sqrt(256)`；TX 额外乘0.25。幅度缩放由接收端 H 吸收。FFT IP 通常使用非酉缩放，必须显式补偿指数。
5. 数据每符号交织：`txBit[i]=sourceBit[(13*i) mod 384]`，i从0开始。接收反交织是按同一索引回写；不是再次前向置换。
6. 导频为种子53的 PRBS7 BPSK，按帧头后的统一符号序号选择8位；帧头从1开始，中间训练也推进该序号。
7. PRBS 状态 `bitget(seed,7:-1:1)`；输出s7，反馈s7 XOR s4，状态移为[feedback,s1…s6]。这是明确的实现约定，避免多项式相同而移位方向不同。

## 4. STF

在 k=±16、±32…±96 共12个载波放置固定 BPSK，IFFT 后时域周期16。取一周期重复10次，共160样本，持续10.417 μs；STF 无单独CP。功率归一到普通有效符号平均功率。

接收滑动相关使用 D=16、W=64：P=sum(conj(r[n])*r[n+D])，M=|P|²/(E1E2)。当前阈值0.40、连续24个位置、能量相对门控；这些是初始参数，需用噪声/干扰实测设定虚警率。初始0.65门限在4dB测试中全部漏检，已补充0.40/0.65对照试验。粗略AWGN下M≈(SNR/(1+SNR))²，故过高门限会直接限制捕获灵敏度。

当前能量相对门控参考整个capture内的最大滑动能量，是离线/整帧缓存模型；流式FPGA需改成前置噪声估计或AGC有效门控，不能把此非因果参考当成已完成的在线检测器。当前只尝试第一个STF候选，失败后继续重搜也列入后续在线状态机。

粗CFO=angle(P)Fs/(2πD)，理论无模糊范围±480 kHz。此范围不是保证捕获范围；多径、噪声和边缘截取会缩小有效范围。

FPGA可用乘积滑动累加，避免64次重复求和。实际AGC的建立时间需确认，10.4 μs可能不足，可增加STF重复数并重新计算开销。

## 5. 两个 ZC 长训练

生成长度201、根25和29的频域ZC：exp(-jπu n(n+1)/201)，移除第101个元素，使其映射200个非DC载波；分别IFFT并加32点CP。根与201互素，但DC打孔、保护带和IFFT映射后不能直接宣称仍具有完整CAZAC性质或恒包络。

包检测后在预测位置附近做LTF1归一化匹配相关，选最大峰。当前采用最强径定时；首达径/能量簇/CP安全窗口选择列为后续任务。

分别算H1=Y1/X1、H2=Y2/X2，由angle(sum(H2*conj(H1)))估计两训练之间残余CFO。间隔288样本，对应细估计模糊范围±26.667 kHz，因此必须保证STF校正已将残余压到此范围内。

细校正后重新FFT，初始H=(H1+H2)/2。不同ZC根必须先除去各自已知序列，再比较相位，不能直接对两个时域符号做重复前导估计。

本模型不使用其他体制的特定峰距常数。暂不采用强固定频域平滑和深衰落填补；避免抹去真实多径。后续比较时域CIR去噪、分段平滑和LMMSE。

## 6. 帧头

| 字段 | 位数 | 当前值/定义 |
|---|---:|---|
| version | 8 | 1 |
| profile | 8 | 1：固定QPSK1/2 |
| payload_bytes | 16 | 644 |
| sequence | 16 | 帧序号 |
| payload_codewords | 8 | 16 |
| flags | 8 | 0，接收拒绝非零 |
| CRC16 | 16 | 对前64位 |
| 信息填充 | 244 | 零，接收验证 |

80位帧头+CRC补零至324，按同一LDPC编码成648位。BPSK占4×192=768槽，后面120位零填充在编码之外。全部768位再按种子31做帧头扰码，防止大量零导致OFDM峰值过高；RX先反转LLR符号再译码。CRC16使用0x1021、初始0、非反射、末异或0的多项式除法。

四符号帧头有明显开销，但与载荷共享LDPC核、便于首版验证；后续短帧头可选卷积码或独立短码，并重新衡量新增RTL与训练开销。

## 7. 载荷与 LDPC

载荷追加CRC32（0x04C11DB7，初始0、非反射、末异或0），对整个5184位按种子93扰码，再分成16个324位块编码。CRC约定不是以太网CRC32，不可直接替换库函数。

采用公开802.11系648位、1/2码率QC校验矩阵，12×24基矩阵、Z=27、88个非空子块、2376条边。这里只复用码矩阵；自有帧不是802.11兼容PHY。来源/许可见THIRD_PARTY_NOTICES。

移位约定：基矩阵值s表示块内校验行i连接变量列(i+s)mod27；-1表示空。编码器利用特定校验结构实现块循环移位和XOR，不用运行时高斯消元。

译码使用layered normalized min-sum，α=0.75（移位加法友好），最大12轮，每轮检查syndrome。浮点参考按标量校验行更新；QC展开的FPGA可并行27行，但需验证bank、饱和与调度等价性。

可选量化实验：输入/消息7位、2小数位，后验/外信息9位、2小数位；对称饱和分别±15.75、±63.75。此实现只量化LDPC消息，不是全接收机定点模型。

syndrome为0不能保证数据正确，因此最终还需CRC。测试用独立GF(2)消元求校验位交叉验证编码器；标准兼容性仍需规范版本和外部golden向量二次核对。

## 8. 导频、中间训练与均衡

导频计算Yp*conj(Hp*Xp)，对其相位做加权拟合phi(k)=a+b*k，再对整个OFDM符号补偿。a代表公共相位，b吸收小量残余定时/SFO相位斜率；不能据此宣称已实现持续采样时钟恢复或消除ICI。

导频间距26载波=1.56 MHz，其时延分辨歧义量级约0.641 μs，小于CP2.083 μs；因此8个导频不够独立估计CP范围内任意时变多径。基线依靠完整LTF/MID信道估计，数据导频只跟踪低维相位变化。高速运动版本需要更密导频、短MID间隔或信道模型约束。

初始噪声估计σ²=mean(|H1-H2|²)/2，假设两次信道近似不变且训练幅度为1。细CFO使用了同一数据，可能带来轻微偏差；后续引入空载波噪声和导频残差对照。

均衡：z=H*Y/(|H|²+σ²)，其中H*表示共轭，符号能量归一为1。QPSK软信息直接用匹配域：LLR_I=2sqrt(2)Re(H*Y)/σ²，LLR_Q同理；正值代表0。与正确补偿MMSE等效增益和输出噪声的解调等价，避免深衰落除法放大。帧头BPSK LLR=4Re(H*Y)/σ²。

MID采用LTF1序列，接收直接刷新全带宽H并保持到下一次MID（因果零阶保持）。离线双向插值可以作为对照，但FPGA实时版本若使用未来MID，需要明确额外缓存与延迟。

## 9. 不可忽略的物理边界

- CP限制的是多径超额时延与定时裕量，单程传播延迟由包检测处理；不能把c×CP说成最大距离。
- 2.083 μs应为时延扩展、前端滤波记忆与FFT窗口误差共同留预算，超CP时单抽头均衡无法消除ISI/ICI。
- Doppler除以60 kHz才是归一化ICI尺度；帧内信道相干时间另行约束MID间隔。
- ZC、导频密度、LDPC和PAPR必须共同评估，不能由某一个模块单独推断“远且快”。
