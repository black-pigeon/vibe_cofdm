# 算法与 FPGA 联合验证计划

## 1. 本目录验证边界

变长PHY v2已新增 `run_variable_tests` 和 `run_variable_sweep`，覆盖未知载荷长度接收、头字段合法性、分块/填充边界及截断拒绝。结果和局限见 [v2验证记录](../results/VARIABLE_PHY.md)。原v1验证继续保留；未实现真实MAC/IP接口或连续流式多帧接收。

随后增加5320个带信号capture的门限评估、理想参数载荷诊断，以及1000个纯噪声窗口检查。使用固定帧数和精确二项置信区间，分别报告同步、头部、载荷失败；采样SNR到dBm的换算统一噪声带宽。结果及复现方式见 [接收门限与灵敏度](../results/SENSITIVITY.md)。该项仍为浮点静态信道模型，不是射频或RTL验收。

当前进一步加入 `compact_fused`、`compact_tracked` 和 `compact_tracked_fixed` 候选：前者在MID处做四象限/移位信道融合，后者增加移位型导频时间跟踪。每点60帧和300帧的共享IQ确认结果见 `../results/tracking_confirm.csv`、`../results/tracking_300_4db.csv`，资源与状态机约束见 [接收机低复杂度改进](接收机低复杂度改进.md)。候选尚未替换默认分支，后续需要定点/RTL对拍。

RTL 目前已覆盖单载波内核和完整 200 载波 MID 控制器；`rtl/run_checks.sh`、`tests/verify_fusion_vectors.py` 可重复执行仿真、lint 和整数参考校验。尚未完成 Vivado 综合、RAM 推断、AXI-Stream 接口、FFT/LDPC 并行调度和全链 bit-exact 对拍。

当前已具备浮点端到端仿真、LDPC消息量化实验及CSV对拍导出。当前信道只有AWGN、静态整数时延多径、恒定CFO和初始整数样本偏移。没有真正模拟SFO、Doppler、PA、ADC量化链或空口干扰。

接收机只接收IQ和公开profile，不使用发送payload、真实SNR、真实CFO、真实起点或信道冲激响应做恢复。测试脚本在恢复后使用真值核对误差。

## 2. 分层测试

| 层次 | 场景 | 指标/验收 |
|---|---|---|
| 比特层 | 字节边界、CRC单bit错误、PRBS周期 | 位序/CRC一致；错误不会静默通过 |
| LDPC | 独立GF(2)编码参考、随机数据、软错误、全0/全1 | syndrome、信息位恢复、迭代次数 |
| OFDM | 无噪声、正负频偏、不同初始偏移 | payload逐字节一致、CRC通过 |
| 多径 | 静态0/3/9等采样延迟 | CFO/定时误差、H误差、PER |
| 负例 | 静默、纯噪声、截断帧 | 正确拒绝；不是可靠虚警概率估计 |
| FPGA向量 | QC移位、码字、交织、LTF、TX IQ | 模块bit-exact或明确数值容差 |
| 量化 | 浮点NMS vs 消息定点 | BER/PER损失、饱和直方图 |

当前`tests/run_tests.m`是功能回归。极端噪声、CRC碰撞、所有包起点、多径和射频失真不可能由少量回归覆盖。

新增 `tests/run_receiver_tests.m` 与 `run_receiver_comparison.m`，覆盖信道去噪、圆周导频估计及四种接收分支的共享 IQ 对照；实际结果见 `../results/RECEIVER_ALGORITHMS.md`。下一阶段优先完成安全 FFT 窗口、oracle 损失分解及非理想信道，再冻结 FPGA 算法规格。

下一轮已增加 `tests/run_compact_tests.m` 与 `run_compact_comparison.m`：路径簇窗选择、FIR去噪、9点搜索、配对新增失败/恢复计数和真实路径下的FFT窗诊断，结果见 `../results/COMPACT_RECEIVER.md`。路径簇窗仍会漏弱首径，不能视为安全性保证；非理想信道和oracle分解仍待完成。

## 3. 扫描矩阵（后续实现所需信道项）

- SNR：围绕瀑布区0.5–1 dB步进，先每点1000帧；达到100个包错或预设最多帧数再停。
- CFO：0、±30k、±135k、±220k、±400k以及模糊边界附近；与低SNR、多径组合。
- 定时：覆盖不同STF截取和完整capture起点；强后径超过首径、FFT窗口CP边界。
- 多径：时延0–31点和超过CP32点；参数含随机复增益、深零陷；CP内也要考虑滤波记忆。
- SFO：±1、±10、±20、±50ppm，连续多帧；没有时钟恢复时测失锁时长。
- Doppler：按fD=v*fc/c计算，分公共频移与多径独立Doppler；不能只用一个CFO冒充时变衰落。
- PA：4倍过采样、AM/AM与AM/PM、逐档回退；测EVM、ACLR、PAPR CCDF和PER。
- 干扰：单音、窄带、邻频、突发，测试自同步错误和LLR可靠性。
- 定点：各位宽组合、FFT缩放、NCO相位截断、LLR饱和；至少双精度/定点共用输入。

## 4. 指标口径

- `sample_snr_db`：有效接收帧内平均复采样信号功率 / 复噪声方差；不是Eb/N0。
- 200有效载波/256FFT时，理想单符号子载波Es/N0约比采样SNR高10log10(256/200)=1.072dB；全帧Eb/N0还要计算CP、头、训练和导频能量，不能只除码率。
- `PER`：同步失败、头失败、译码/CRC失败和payload不一致全部计入。当前仿真也将错误payload视为包错，不仅依赖CRC。
- `conditional_payload_BER`：只统计已进入载荷译码的帧，必须与PER同时给出，不能丢弃同步失败后宣称低BER。
- `goodput`：基线净速率×(1-PER)，当前不含ARQ/TDD开销；测系统吞吐时另行扣除。
- 0/20包错不代表PER=0；独立伯努利假设下95%单边上限约1-0.05^(1/20)=13.91%。0/1000约0.30%。
- 持续处理能力以最大迭代次数、最大搜索量和队列不溢出为准，平均一轮译码时间不能代替最坏时延。
