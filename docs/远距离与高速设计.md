# 如何兼顾传得远与传得快

## 1. 先明确目标不是一个调制阶数

“最远仍然能收到帧”和“在一定距离连续输出高速数据”是两个验收指标。建议定义最低可靠速率、目标距离处的净吞吐、允许PER、P95端到端时延、移动速度/遮挡条件。载频、平均发射功率、天线和接收NF尚未给定，不能从15.36M或LDPC推算实际覆盖公里数。

链路质量应使用有效SNR/子载波SINR、EVM、头失败、载荷PER和译码轮数联合评估。RSSI高不等于可支持高阶QAM，窄带干扰和频率选择性深衰落会使平均SNR失真。

## 2. 链路预算

```text
P_rx = P_PA_reference - OFDM_backoff + G_tx - L_tx - L_path + G_rx - L_rx
N_rx = -174 + 10log10(B_noise) + NF  (dBm，约290K)
Sensitivity = N_rx + required_SNR + implementation_loss
允许路径损耗 = EIRP + G_rx - L_rx - Sensitivity - fade_margin
```

`link_budget.m`提供可替换参数的计算器。默认例子仅用于演示：2.4GHz、PA参考30dBm、回退6dB、收发天线各6dBi、馈线各1dB、NF5dB、噪声带宽12MHz、所需SNR6dB、实现损失3dB、衰落裕量15dB。所需6dB不是本次测得的门限。自由空间等效距离未考虑遮挡、地面反射、菲涅尔区、天线方向/极化失配和干扰，不能当作覆盖承诺。

降低NF、减少馈线损失、增加天线增益、提高线性平均发射功率，可能比盲目增加译码轮数更直接。但天线增益通常牺牲波束宽度，移动端需要姿态/指向裕量。

## 3. 调制编码自适应 ACM

在相同27个数据符号、同样训练/头/MID开销下的规划值如下。只有QPSK1/2已实现，其余不是当前config可直接切换的模式。

| 候选模式 | 净载荷字节 | 理想帧净速率 Mbps | 方向 |
|---|---:|---:|---|
| BPSK 1/2 | 320 | 3.724 | 弱信号救援/控制；增益需实测，不保证比QPSK在同Eb/N0更好 |
| QPSK 1/2 | 644 | 7.494 | 当前可靠性基线 |
| 16QAM 1/2 | 1292 | 15.034 | 中等SNR |
| 16QAM 3/4 | 1940 | 22.575 | 更好的EVM与信道估计 |
| 64QAM 2/3 | 2588 | 30.115 | 高SNR、高线性度 |
| 64QAM 3/4 | 2912 | 33.885 | 7020译码吞吐、相噪、PA要求更高 |

以`plan_budget.m`计算结果为准。更高码率要换对应的标准QC基矩阵，不可简单截去当前校验位而宣称达到同等编码性能。

MCS门限应由端到端PER曲线反推，比如先以PER≤1%作为应用可调整目标。闭环设计需要ACK/CQI反馈、上下切换迟滞、连续好帧计数、连续坏帧快速降档和反馈超时回退；未实现之前仍是固定MCS。

远距离可靠控制可以另设低速profile、增加前导能量或更强编码；时域重复的能量收益来自更多时间/能量，不是免费链路增益。要同时保证吞吐和时延。

## 4. 同步必须先于编码达到目标灵敏度

低SNR时，最先失败的可能是STF/LTF或帧头，而不是载荷LDPC。需要分别画捕获概率、帧头成功率和条件译码PER；只给完美同步下BER会高估远距离能力。

优化方向：归一化多尺度STF检测、峰群/首达径定时、重复训练相干积累、整数/小数CFO分级、捕获失败重搜。所有增加的搜索量要计入7020周期。

当前STF无模糊CFO理论±480kHz，细CFO±26.667kHz。实际范围需扫频偏、SNR、多径和振荡器ppm组合，不用理论范围替代捕获曲线。

## 5. CP、导频与运动

CP2.083μs对短时延信道开销合理，但远距离不是必然长时延，近距离室内也可能有严重多径。应依据实测功率时延分布和最大超额时延选择CP32/64候选，而不是根据直线距离选择。

60kHz间隔相对有利于频偏/Doppler容忍；对高速链路仍需SFO跟踪、相位噪声评估及MID刷新。当前8导频用于公共相位/斜率，不能独立重建整个CP范围的时变信道。更密导频与更频繁MID会降低净速率，应以goodput而非裸速率优化。

SFO闭环应估计跨符号相位斜率变化，驱动插删样或分数延迟重采样。只旋转每个符号的线性相位不能永久修复采样时钟漂移。

## 6. PAPR、功放与频谱效率

OFDM峰值要求PA回退，回退直接减少平均辐射功率。头信息大量零填充尤其危险；本模型对编码后的头和填充位扰码，避免大量同相BPSK载波叠加。

必须使用≥4倍过采样测PAPR CCDF，并联动PA的AM/AM、AM/PM、EVM和带外谱。当前`tx.paprDb`只是原采样率离散峰值，不能用它设定最终回退。单帧PAPR也不能代表CCDF尾部。

推荐顺序：归一化和头扰码 → PA线性区测量 → 削峰/滤波基线 → 适度CFR与EVM/OOB联合优化。DFT-s-OFDM可列为大改版研究，但会改变映射、导频和均衡，不能当作当前COFDM的无代价开关。WOLA/加窗也会消耗CP裕量，需重新验算有效保护区。

## 7. 编码、交织和抗干扰

- 648短码优先低延迟/资源；1296/1944或其他成熟QC码可能改善编码增益，但RAM和译码延迟增加。
- 当前符号内仿射交织简单，便于RTL；跨符号/跨码字交织可分散突发衰落，代价是缓存和时延。
- 不要将深衰落子载波硬补成“好信道”；通过正确LLR让译码器知道它不可靠。
- 窄带干扰下应估计逐载波噪声、擦除/降权并研究自适应避让；禁用子载波后必须重新定义位装载、码字长度匹配和头部profile。
- HARQ/ARQ提升交付率但占用时隙；应用吞吐统计必须扣重传和反馈。

## 8. 优先投入顺序

1. 先给出载频/功率/天线/NF/速度和距离处的净吞吐要求，形成预算。
2. 测全链捕获与帧头门限，修复“译码可用但根本捕获不到”的损失。
3. 优化PA回退、接收前端和信道/LLR质量，再衡量增加LDPC轮数的收益。
4. 用27路QC译码原型确认7020可持续的处理上限，再实现16QAM和其他码率。
5. 通过ACM在可靠性与速率之间切换；64QAM必须同时满足EVM、线性度和译码预算。
6. 每次优化交付同一测试集下的PER、goodput、时延、FPGA资源与功耗对比。
