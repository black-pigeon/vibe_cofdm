# 面向 Zynq-7020 的低复杂度接收算法

本轮保持原空口、训练数量、载荷、QPSK/LDPC 和 12 轮译码上限，优化接收机。候选模式 `compact` 是浮点算法实现，LDPC 可启用既有消息量化；没有完成整链定点或 RTL 综合。

## 1. 比较对象与取舍

| 模式 | FFT 窗 | 信道估计 | 导频斜率候选 |
|---|---|---|---:|
| `proposed` | 上一轮最强峰 | 63 点时延支撑 SVD 正则化投影 | 33 |
| `safe_window` | 本轮能量簇选择 | 同上 | 33 |
| `compact_channel` | 能量簇选择 | 相位居中的 7 抽头频域 FIR | 33 |
| `compact` | 能量簇选择 | 同上 | 9 |

以上四种都使用信道误差近似和圆周导频拟合。默认 `config()` 仍为最早 `baseline`，以保留已有回归与向量。运行本轮候选使用 `cofdm.receiver_config(cofdm.config(),'compact')`。

`compact_fir5` 保留较早的 5 抽头筛查方案。采用 7 抽头增加少量移位加法以降低噪声，不增加核心复旋转数量。FIR 与 SVD 不在所有信道上性能等价，`safe_window` 留作性能参考。

## 2. 复用相关结果选择 FFT 窗口

原接收机已计算最多 193 个 LTF1 匹配相关分数。本轮复用这些分数，不新增一轮长训练相关或额外 FFT：

1. 取最强峰两侧 CP 范围外的分数均值，作为相关背景估计。
2. 阈值取 `max(0.04*最大峰, 4*背景均值)`；在最强峰 ±31 范围内保留超过阈值的局部极大值。
3. 在包含最强峰、宽度 32 的候选簇中选择累计能量最大者。前缀和/滑动和代替逐窗口累加。
4. 设最早/最晚保留峰位置为 e、l，选择 `max(e-2, l-CP+1)`，并限制在已有搜索范围内。
5. 从该位置重新提取已有双 LTF FFT，后续 CFO 和信道估计自然包含新的相位基准。

对真实整数路径 d_min、d_max，理论安全窗为 `[d_max-CP, d_min]`。上述算法只从带噪相关分数估计支撑，可能漏掉弱首径、选入旁瓣或丢弃超 CP 路径，因此不是安全保证。幅度很弱的路径也可能有业务意义，不能因低于门限就视为物理不存在。

最初筛查使用 6 倍背景中位数，最终版本改用 4 倍算术均值，去掉排序网络；最终独立种子结果与这版实现对应。背景均值受异常峰污染的风险仍需干扰试验覆盖。

新增 `sync.ltfPeakStart` 保存原匹配峰，`sync.ltfUsefulStart` 保存实际 FFT 起点。`sync.frameStart` 仍是由最强峰推算的帧参考，不能再拿它单独判断新算法 FFT 窗口是否正确。`sync.window` 暴露路径偏移、门限与窗口偏移。

FPGA 中可把分数保存在小 RAM 内，两次遍历完成背景、门限和峰筛选；能量簇选择用累加/减法与比较器。193×24 bit 仅是约 4632 bit 的候选容量，24 位分数尚未定点验证。原有归一化相关的复乘、能量和除法成本仍然存在。

STF仍使用原有整capture相对能量门控，且只尝试第一个候选。本轮没有把整个同步器改成在线流式状态机，也没有完成持续虚警率验证。

## 3. 相位居中 + 7 抽头 FIR 信道去噪

当 FFT 窗选得正确，路径相对 FFT 起点主要落在 `[0,32]` 内。先将时延中心搬到 d0=16，使频率响应变化减缓，再用局部滤波：

```text
R[k] = H_LS[k] * exp(+j*2*pi*k*16/256)
w = [1,6,15,20,15,6,1]
S[k] = sum_i(w[i]*valid[k+i]*R[k+i]) / sum_i(w[i]*valid[k+i])
H_hat[k] = S[k] * exp(-j*2*pi*k*16/256)
```

按实际整数频率索引建立 -100…100 网格。DC 和保护带是缺失观测，权重为零；跨 DC 时保留其位置，不把 -1 和 +1 当作相邻频率，也不把缺失观测当作真实零信道。边缘重新归一化。

对每个频点，利用对称性：

```text
A = R[k-3] + R[k+3]
B = R[k-2] + R[k+2]
C = R[k-1] + R[k+1]
numerator = A + (B<<2)+(B<<1) + (C<<4)-C + (R[k]<<4)+(R[k]<<2)
```

对应约 9 次复加/减每频点；系数 6、15、20 都可移位加减。内部完整窗口除以 64 可移位，DC/边缘的归一化倒数查表。实际定点需明确累加保护位、舍入和饱和，不能直接截断。

预旋转/逆旋转最多 400 次复乘每更新。d0=16 时只有 16 个不同旋转系数，可用小 ROM；其中 ±1、±j 还能实现为交换/符号操作，预算暂按全部复乘保守计算。

### 偏差必须单独记录

完整 FIR 窗口内，单路径 d 的幅度被乘以

```text
G(d) = cos(pi*(d-16)/256)^6
```

所以这不是无偏信道估计。CP 端部路径约有一成幅度衰减；多径相消附近可能改变局部相位与软信息，DC/边缘响应也不同。新测试直接验证该解析响应，避免用“无噪声必等于原信道”的错误假设验收。

估计噪声方差为 `observationVariance * sum(w_valid²)/sum(w_valid)²`，只描述噪声传播，不包含滤波偏差、ISI/ICI 和支撑误判。当前 LLR 使用它是工程近似，后续需要校准，尤其不能未经验证迁移到 64QAM。

## 4. 导频斜率从 33 点减为 9 点

保留上一轮相同的圆周目标函数、±1 样本搜索范围和 1/8 样本先验；均匀候选由 33 减至 9，在最大点左右做抛物线插值。

搜索系数由公开的导频位置及斜率网格决定，可离线存 ROM；8×9=72 个复系数。每帧 31 个头/数据符号的搜索主体从 8184 降到 2232 次复乘累加，减少约 72.7%。公共相位提取、相关输入、逐载波补偿旋转与倒数等公共成本未包含在这个比例内。

9 点加插值不是原优化问题的精确解，边界最大值不能双边插值。测试覆盖跨 ±π 相位支路与部分非零斜率，但仍未实现 SFO 重采样或时变状态预测。

## 5. 可核对的算法预算

由 `receiver_budget()` 给出；每帧 4 次信道估计，帧槽 687.5 μs。

| 项目 | 上一轮 `proposed` | 本轮 `compact` |
|---|---:|---:|
| 信道估计核心复乘/更新 | 25,200 次复 MAC | ≤400 次复旋转 |
| FIR 额外运算/更新 | 不适用 | 约 1800 次复加/减，加归一化 |
| 上述核心复乘/帧 | 100,800 | ≤1600 |
| 上述核心复乘速率 | 146.618 M/s | ≤2.327 M/s |
| 信道主系数 ROM | U 基矩阵 403,200 bit | 旋转+归一化/噪声系数 ≤6912 bit |
| 导频搜索复 MAC/帧 | 8184 | 2232 |
| 导频搜索系数 ROM | 8448 bit | 2304 bit |

ROM 对比统一假设复数每分量 16 位、标量 16 位，只是容量估算。SVD 方案的增益/协方差运算及额外系数未计入左栏；FIR 的方差与归一化实乘、数据缓存、状态机未计入复乘栏。不能把核心复乘减少约 98.4% 写成整个接收机 DSP 减少 98.4%。BRAM 端口和银行结构也使 bit 容量不等于综合块数。

在假设 122.88 MHz 下，一个复乘通路若能每周期接受一组输入，信道旋转与导频搜索主体合计约 3832 个启动周期/帧，帧周期预算 84480。这个比例只是调度下界；FFT、LTF 搜索、LLR、公共相位、LDPC、RAM 冲突和延迟全部需要另计。不能据此声称一个通路已经足够实时整链。

## 6. 实现优先级与性能边界

1. 优先定点化窗口分数/峰检测、FIR 累加/归一化和 9 点导频搜索，给出逐模块量化误差及饱和统计。
2. 继续保留 `safe_window` 作性能参考，测低复杂度分支在随机/分数时延、深零陷和干扰下的差距；低 SNR 下不能用均方误差单独替代 PER。
3. 测全接收机周期，当前完整 LTF 匹配搜索仍可能成为显著开销。先做可复用/分级搜索调度，再决定硬件并行度。
4. SFO/Doppler/相噪尚未进入信道模型，暂不引入激进的 MID 时间平均，以免把静态信道收益误当成移动性能。
5. LDPC 平均轮数降低不意味着可以缩减最坏轮数预算；仍须保证队列不溢出。27 路只是现有 QC 矩阵的实现候选。
