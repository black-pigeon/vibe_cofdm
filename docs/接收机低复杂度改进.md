# 面向 Zynq-7020 的 PHY 接收机改进方案

日期：2026-09-28。本文记录当前实现的低复杂度候选，不把候选分支误写成已经冻结的 FPGA 规格。原有 `compact` 仍是默认基线；新增 `compact_fused`、`compact_tracked` 和 `compact_tracked_fixed` 通过 `config_v2` 或 `receiver_config` 显式选择。

## 1. 改进目标

灵敏度评估显示，1500 字节长包在 4 dB 左右的失败以载荷 LDPC/CRC 失败为主；包头并不是主要限制。CP 边缘多径下还会出现 FFT 窗和信道估计误差。当前接收机每个 MID 直接用新的训练符号替换信道估计，低 SNR 时会把噪声较大的估计完整带入后续数据。

本轮增加两个因果、流式候选：MID 信道估计与历史估计做相位对齐的一阶融合；用历史相位和相位误差做低带宽导频跟踪。它们不增加矩阵分解、额外 FFT 或大规模缓存，并保留突变门控以避免固定平滑拖慢时变信道。

## 2. 因果信道融合

设上一估计为 `H_old`，当前 MID 估计为 `H_new`。先使用8个导频位置计算复相关，确定四象限旋转 `r∈{1,-j,-1,j}`，然后：

```text
H_align = r · H_new
d       = Σpilot |H_new - H_old|²
if d > 4·Σpilot(σ²_old + σ²_new): α = 1
else:                             α = 1/4
H_next  = H_old + α·(H_align - H_old)
```

`α=1/4` 在 RTL 中是算术右移2位；突变门控的乘4是左移2位。四象限旋转只做符号翻转和实虚交换，不使用 `atan2`、CORDIC、除法或复数乘法。当前实现只用导频计算相关和创新门限，减少额外乘法；全带宽融合通过符号交换、减法、右移和加法完成。

| 项目 | 候选开销 | 7020实现建议 |
|---|---:|---|
| 导频相关和创新门限 | 8个复数乘加/MID | 1个复乘流水复用；乘4用移位 |
| 全带宽融合 | 200次符号交换/加减/右移/MID | 1 lane 顺序更新，放在MID符号期间 |
| 历史信道状态 | 200×2分量×18 bit≈7.2 kbit | 一块BRAM或寄存器文件；新估计可流式读取 |
| 乘法器 | 不新增全带宽乘法；相关和复乘可共享 | 1～2个DSP48候选，需综合确认 |
| 关键路径 | 交换→减法→算术移位→加法 | 插入一级寄存器；不放入FFT主临界路径 |

## 3. 导频相位时间跟踪

`compact_tracked` 在已有9候选圆周斜率搜索后增加一个小状态：

```text
phase_pred = phase_prev + frequency_prev·Δsymbol
error      = wrap(phase_measured - phase_pred)
phase      = phase_pred + error/2
frequency  = frequency_prev + error/16
```

`wrap` 只需符号和边界处理，`1/2`、`1/16` 是右移。误差超过π/2时重新捕获，防止错误状态长期锁死。中间训练造成符号索引间隔2，状态机按实际间隔更新。当前相位斜率搜索本身仍是已有的9点ROM相关，没有新增搜索点。

## 4. 配对实验观察

四象限旋转版本、相同随机IQ输入、每点20帧：

| 信道/SNR | compact | compact_fused | compact_tracked |
|---|---:|---:|---:|
| AWGN 3 dB | 13/20 | 7/20 | 9/20 |
| AWGN 4 dB | 0/20 | 0/20 | 0/20 |
| 短多径 3 dB | 19/20 | 13/20 | 7/20 |
| 短多径 4 dB | 4/20 | 1/20 | 1/20 |
| CP边缘 3 dB | 20/20 | 20/20 | 16/20 |
| CP边缘 4 dB | 16/20 | 8/20 | 8/20 |

样本量仍小，不能作为最终门限。收益集中在载荷失败；同步失败数量基本没有改变。200 Hz动态压力测试在4 dB下跟踪候选从8/10降到6/10；1000 Hz时所有候选都接近失效，说明简单一阶跟踪不能替代时变信道估计。

随后进行的确认组每点60帧（AWGN、短多径、CP边缘，3/4 dB）中，三种模式总错包数为 `compact=207/360`、`compact_fused=148/360`、`compact_tracked=121/360`。这是同一输入配对比较，不是最终PER验收；跟踪版相对融合版仍有逐场景取舍，默认配置因此保持不变。

进一步的正式4 dB配对组每个条件300帧，结果如下：

| 信道 | compact | compact_fused | compact_tracked | 同步失败（各模式） |
|---|---:|---:|---:|---:|
| AWGN | 21/300 | 4/300 | 1/300 | 1 |
| 短多径 | 50/300 | 5/300 | 2/300 | 1 |
| CP边缘多径 | 243/300 | 60/300 | 19/300 | 9 |

结果文件为 `results/tracking_300_4db.csv`。跟踪版在这组测试中显著改善CP边缘多径，但CP边缘仍未达到1%工作点；它也没有减少同步失败。因此下一轮需要把FFT窗/弱径检测和跟踪算法分别做消融，不能把剩余错误全部归因于信道融合。

另外对 `compact_tracked` 做了 `llrScale={1,0.75,0.5,0.25}` 的共享IQ缩放筛查（3/4 dB、三类信道、每点60帧），四档每个条件的错误数完全一致。当前浮点归一化最小和译码对整体LLR缩放近似齐次，因此没有观察到收益；这不等于定点量化时没有作用。默认仍为1，后续应在7位LLR饱和和译码消息量化后重新扫描，而不是在浮点链路中增加缩放硬件。

针对 CP 边缘多径还比较了 early、center、loose 和 relaxed 四组窗口门限（每点60帧，4/5/6 dB）。本次随机数据下四组错误数完全相同，说明简单调低路径阈值或改变 early/center 选择没有提供可重复收益；因此没有把窗口门限改成更激进的值。`results/window_comparison.csv` 保留了这组负结果，后续应改进弱径判决特征或做真实分数时延模型，而不是继续盲调常数。

## 5. FPGA 数据通路

```text
MID_DETECT → READ_H_OLD / READ_MID_LS → PILOT_CORR_0..7
→ QUADRANT_SELECT → INNOVATION_SUM / GATE
→ FUSE_CARRIER_0..199 → WRITE_H → NEXT_DATA
```

`PILOT_CORR`只保存复相关累加器；`FUSE_CARRIER`每周期处理一个有效载波。建议使用双口BRAM或 ping-pong 寄存器避免读写冲突，更新不能阻塞 FFT、解交织或 LDPC 输入 FIFO。

定点初始建议：H 实部/虚部沿用18 bit、14 bit小数；相关累加器增加3个保护位；融合差值增加1位后右移2位；相位状态采用有符号圆周定点；异常门控优先保守地使用 `α=1/4`。LLR仍需独立做饱和、缩放和迭代扫描。

当前不替换 `compact` 默认分支：候选只有小样本验证，跟踪版在低 SNR AWGN不总是优于融合版，也尚未完成 Vivado 综合、时序、BRAM/DSP 占用和全链定点对拍。下一步应在相同 IQ 数据集上做至少300帧/点的候选对照，补充分数时延、SFO、Doppler、窄带干扰和 AGC/ADC 模型，再冻结默认 profile。

入口：`run_tracking_comparison`；资源输出使用 `receiver_budget()`，其中已加入融合候选的字段。

RTL 内核初版已放在 `rtl/cofdm_quadrant_select.sv` 和 `rtl/cofdm_fusion_lane.sv`。前者实现四象限选择，后者实现单载波移位融合和饱和；测试平台在 `rtl/tb/`。它们还不是完整 MID 状态机，目的是先固定算术位宽、符号扩展、饱和和单周期接口，再接入 BRAM 控制器。可用 `iverilog -g2012` 运行测试，并用 Verilator 对单模块做 lint。
