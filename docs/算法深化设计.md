# COFDM 算法深化设计与对照实验

本文件是工程算法规格与研究计划。固定空口基线仍为 v0.1；新增的是接收算法实验分支，不是新的已定型 PHY。应先验证接收机损失、信道适用范围与帧开销，再冻结实现架构。Zynq-7020 的复杂度是设计约束，27 路 LDPC 只是此前基线的一种实现候选。

本文件保留第一轮算法与计划。后续已新增能量簇 FFT 窗口、7 抽头频域 FIR 和 9 点导频搜索，详见 [低复杂度接收机设计](低复杂度接收机设计.md)；oracle 损失分解及 SFO/时变信道仍待实现。

## 1. 当前设计为什么仍然基础

15.36 MS/s、FFT256、CP32、ZC、导频、LDPC 只是模块配置，不等于经过优化的物理层。以下决策目前缺少充分证据：

| 环节 | 原版实际实现 | 需要解决的问题 |
|---|---|---|
| 检测 | STF 单门限、首个候选、全 capture 相对能量门控 | 灵敏度与虚警如何兼顾；失败重搜；前导前没有干净噪声段怎么办 |
| 定时 | LTF 最强相关峰 | 最强径不一定是安全 FFT 起点；CP 内多径也会产生错误截窗 |
| 频偏 | STF 粗估计、双 LTF 细估计 | 低 SNR 估计方差、粗细模糊范围交接、残余频偏随时间漂移 |
| 信道 | 双训练逐载波 LS 平均、MID 单次覆盖 | 200 个独立带噪估计没有充分利用有限时延结构；新 MID 可能让估计变差 |
| 导频 | 8 导频角度 unwrap 后直线拟合 | 弱导频造成相位展开错误；独立逐符号斜率拟合的噪声过大 |
| LLR | 假设估计的 H 准确，整带一个噪声方差 | 信道误差/ICI/干扰使软信息过度自信；高阶 QAM 会更敏感 |
| 编码 | 648、1/2、NMS α=0.75、12 轮 | 码长、算法、量化和轮数没有在相同条件下选优 |
| 交织 | 每个符号固定仿射置换 | 对持续频率零陷、窄带干扰和突发失效的分散能力未验证 |
| 帧开销 | 4 个头符号、3 个固定 MID | 对慢变/快变信道是否合理；短帧净吞吐损失明显 |
| 射频模型 | 静态整数多径、恒 CFO、AWGN | 不足以验证运动、异源时钟、功放和真实干扰 |

因此，第一阶段的目标是减少实现损失、建立可解释的性能边界，暂不以增加调制阶数作为主要进展指标。

## 2. 先建立损失分解，而不是只看一条 BER 曲线

需要分开统计：捕获失败、头失败、载荷码字失败、CRC 失败、整体 PER、实际 goodput、P95/P99 延迟和最大译码轮数。漏检不能从 BER 分母中悄悄消失。

后续应建立四层诊断（下面的 oracle 尚未实现，不能接到实际接收机）：

1. 理想同步、真实信道、真实噪声：测编码/映射本身的基准；
2. 理想同步、估计信道：量化信道估计与软解调损失；
3. 实际同步与实际估计：量化捕获、定时和频偏损失；
4. 在第 3 层增加 SFO、Doppler、相噪、PA、干扰：量化模型遗漏的损失。

对照必须共享同一 payload 和噪声样本，固定发射平均功率、占用带宽、净载荷及开销口径。比较不同训练长度时，不能同时增加能量却把收益全部记为算法收益。记录采样 SNR、Es/N0 和包含帧开销的 Eb/N0 换算。

初步工程目标可取 PER≤1%，但要由应用确认。每点先用小样本找到瀑布区，再按预先声明的固定样本数或顺序试验规则累计足够错误事件，报告置信区间。20 帧仅用于筛查；0/20 的 95% 单边 PER 上限仍为约 13.9%。

## 3. 已实现的第一轮算法实验

发送端、编码、同步、训练数量及帧长全部保持一致。用 `cofdm.receiver_config` 选择四种接收机：

| 模式 | 信道估计 | 软信息 | 导频 |
|---|---|---|---|
| `baseline` | 原始 LS | 原始噪声模型 | unwrap + WLS |
| `delay` | 时延子空间正则化 | 原始噪声模型 | unwrap + WLS |
| `delay_uncertainty` | 同上 | 加入近似信道误差方差 | unwrap + WLS |
| `proposed` | 同上 | 同上 | 圆周相位目标 + 斜率先验 |

默认 `config()` 保留 `baseline`，便于重现此前结果。`proposed` 是待扩展验证的候选，不是覆盖全部信道的最终推荐。

### 3.1 时延子空间信道估计

有限超额时延意味着不同子载波的 H 并非相互独立。只在实际观测的 200 个子载波上构造

```text
F[k,l] = exp(-j*2*pi*k*l/256)
H_LS = F*h + w
tau = max(mean(|H_LS|²) - observation_noise, floor) / L
lambda = observation_noise / tau
h_hat = (F'F + lambda*I)^(-1) F' H_LS
H_hat = F*h_hat
```

双 LTF 平均的观测噪声约为 nv/2，单 MID 为 nv。采用均匀时延功率先验，是正则化 LS / 简化 LMMSE 思路，尚未使用测得的 PDP。SVD 只依赖公开载波配置，缓存后以 `U diag(s²/(s²+lambda)) U'` 运算，避免每帧求逆。

当前定时锁最强径，所以估计支撑暂取 -31…31，共 63 点，允许首径位于参考点之前。它不意味着物理 CP 能容忍 62 点时延扩展；安全 FFT 窗仍需单独满足 CP 条件。保护带和 DC 是未观测频点，不能补成零信道后直接 IFFT 截断，否则会产生系统性偏差。

后续比较固定短支撑、自适应功率时延窗、低秩投影与已知 PDP 的 LMMSE 上界。不能向实际接收机提供仿真真实路径或延迟。

### 3.2 把信道不确定度传给 LLR

在符号平均能量为 1 的近似下，使用

```text
sigma_eff[k]² = sigma_noise² + sigma_channel_error[k]²
LLR_I = 2*sqrt(2)*Re(conj(H_hat)*Y) / sigma_eff²
```

误差方差来自上述先验下的后验协方差对角，属于 plug-in 近似。它不包含支撑失配、残余 CFO/ICI、导频相位估计误差或 MID 老化，不能当成已经校准的真实误差概率。对于高阶 QAM，信道误差项与候选星座幅度有关，不能直接照搬 QPSK 常数能量公式。

单独增加一个 LLR 缩放不一定改善 NMS：若没有饱和，许多最小和运算对全局正缩放保持硬判决不变。必须通过消融验证其实际价值，再考虑引入逐载波 SINR、LLR 校准与干扰擦除。

### 3.3 导频圆周拟合与斜率约束

用复导频相关直接最大化圆周目标，避免先对每个导频 `angle` 再 `unwrap`。对相位斜率 b 搜索，公共相位 a 由相关和角度求出：

```text
e_p = Y_p * conj(H_p*X_p) / (nv + channel_error_variance_p)
J(b) = 2*|sum(e_p * exp(-j*b*k_p))| - 0.5*(b/sigma_b)²
a_hat = angle(sum(e_p * exp(-j*b_hat*k_p)))
```

当前用 33 个候选斜率、局部抛物线细化；搜索相对当前 H 的 ±1 样本斜率，先验标准差为 1/8 样本。这个先验适用于本轮静态短帧筛查，可能压制真实较大 SFO 或变化，不能据此宣称已支持运动或异源时钟。下一阶段要由跨符号状态预测提供先验均值与协方差，比较 α-β 跟踪器与小状态 Kalman，而不是长期固定在零附近。

### 3.4 本轮没有解决的事项

MID 仍是逐次替换，没有做时间滤波；也没有修改最强径定时、噪声估计器、FEC 参数或帧头编码。这些限制使每一项变化的收益可追踪，但不能把实验分支称为完整优化版本。

## 4. 下一阶段最优先：安全 FFT 窗口与在线捕获

设最早与最晚有效路径为 d_min、d_max，FFT 窗口相对发送有效符号起点为 t。理想整数多径下避免跨符号污染需满足：

```text
d_max - CP <= t <= d_min
```

因此“相关最高峰处截取 FFT”不一定成立。若晚径最强，t>d_min，早径会带入下一符号，单抽头均衡无法修复。实施路线：

1. 用 STF 提供候选区间，长训练相关得到路径能量簇；
2. 在噪声阈值下估计有效能量支撑，排除孤立伪峰；
3. 根据能量覆盖率和 CP 余量选择偏早 FFT 窗口，留前端滤波/定时抖动裕量；
4. 用另一 LTF 的一致性确认候选，失败后恢复搜索；
5. 将整 capture 能量门控换成流式噪声/AGC 状态机，并统计连续流虚警。

验收必须包含首径弱于后径、路径跨 CP 边缘、分数采样时延、纯噪声和周期干扰。不能只在首径最强的 [0,3,9] 场景报告同步成功率。

## 5. 随后开展的联合研究

| 优先级 | 研究内容 | 比较方法及交付 |
|---|---|---|
| P0 | 实际同步损失与安全 FFT 窗 | 同一信道上与 oracle 对照；捕获率、窗位置、CFO误差及 PER |
| P0 | 信道结构去噪与导频稳健性 | 当前四组消融；随机/长时延/分数时延，不仅固定三径 |
| P1 | 信道时间跟踪 + SFO | 估计 H 的过程噪声，MID 创新门控/IIR；相位斜率状态驱动 Farrow 重采样，验证长期不失锁 |
| P1 | LDPC 与软信息协同 | 648/1296/1944 同码率比较；NMS/OMS、4/8/12/16轮、量化、LLR校准；按总吞吐/延迟对齐 |
| P1 | 交织与干扰 | 对比符号内/跨符号/跨码字；测深零陷和窄带/突发干扰；统计增加的存储与时延 |
| P1 | 帧结构开销 | 头码缩短、MID每4/8/16符号、训练能量分配；以固定平均功率下 goodput 选优 |
| P2 | 16QAM、多码率与 ACM | 先标定每 MCS 的 PER 门限，再设计迟滞、反馈延迟与回退；64QAM 取决于实测收益 |
| P2 | PAPR 与 PA | ≥4倍过采样；扫回退，比较 EVM/ACLR/PER 与平均辐射功率，不能只优化 PAPR 数值 |

帧头有两条独立路线：在保持当前空口时，将已知 244 个零信息位作为译码先验；在新 profile 中，真正缩短编码并省去相应传输位。二者不同，修改传输格式必须重新计算净速率和头可靠性，不能把后验验证填充位等同于已利用先验。

慢变信道可以减少 MID，快变信道可能必须增加 MID/导频。先有 Doppler 与 SFO 模型，才能判断自适应开销；固定每 8 符号只是起点。

## 6. 算法阶段如何考虑 7020

保留双精度性能参考，同时为每个候选给出运算量、ROM/RAM、延迟与定点敏感性。收益稳定后再冻结 RTL，不先把 27 路等并行度当作不可更改的前提。

- 当前 200×63 基矩阵的双向投影约 25,200 次复 MAC/信道更新，4 次/帧约 100,800 次，按 687.5 μs 约 1.47 亿次复 MAC/s，尚未计协方差更新。它明显不是“低成本加几行代码”。候选：低秩截断、小支撑、FFT型投影、分段Wiener；各项须重新验证损失。
- ROM 200×63 复系数即便每个分量 16 位也约 403,200 bit，约 11 个 BRAM36 的容量下界，实际受端口/布局限制。SVD/动态大矩阵求逆不应在实时 PL 中执行。
- 33 斜率×8 导频的搜索约 264 次复乘加/符号；31 个头/数据符号约 8184 次/帧。相关旋转系数可 ROM 化，再比较粗细搜索或局部迭代降低开销。
- 仿真降低平均 LDPC 轮数有价值，但队列和持续吞吐仍须按最大轮数、码字到达率及缓冲容量设计。
- 先对信道投影、相位状态、LLR 做定点消融，再接已有 LDPC 消息量化。当前没有全链定点或综合结果。
