# 局部定点与 FFT 窗口优化

日期：2026-09-28。面向 Zynq-7020，在上一轮 `compact` 接收机上继续优化。此处仍是自组网系统所需的单链路 COFDM PHY：尚未实现组网发现、MAC、时隙同步、路由或多节点冲突处理。

## 1. 三种可复现接收模式

| 模式 | 窗口 | 信道 FIR | 导频搜索 ROM | LDPC |
|---|---|---|---|---|
| `compact` | 原能量簇、向前预留两点 | 浮点 | 浮点 | 可选消息量化 |
| `compact_center` | 估计安全区间中部 | 浮点 | 浮点 | 同上 |
| `compact_fixed` | 同上 | 逐级舍入/饱和 | 18位、16小数位 | 同上，默认不自动量化 |

发送帧、训练数量、调制、编码、载荷和功率不变。默认 `config()` 和无参数 `run_demo()` 仍保留最初的 `baseline`；本轮两个新模式是可选研究分支。`fixed` 仅表示指定模块定点，不能解释为整链定点接收机。

## 2. 不增加相关搜索的窗口调整

已有峰筛选给出估计首/末径位置 e、l，原窗口为 `max(e-2,l-CP+1)`。新候选改为：

```text
window = max(l-CP+1, floor((e+l-CP)/2))
```

它将估计出的剩余 CP 裕量分配到两边。例如真实路径是 0/10/23，而漏掉首径只检出 10/23 时，原方法取 8，新候选取 0，后者位于真实安全区间 [-9,0]。计算只增加加法、右移和比较；LTF相关、FFT数量不变。

但它没有提升路径检测器本身的检出能力。当路径为 0/12/25、只检出 12/25 时，新窗口取 2，仍不满足真实安全条件。簇估计包含伪峰、漏掉晚径时，新位置也可能退化。因此保留原窗口分支对照，不默认替换全部接收模式。

实际对照同时报告PER与真实整数路径下的FFT窗诊断。真值只用于接收结束后的评价，不传入接收机。

## 3. FIR 的逐级定点参考

不依赖 Fixed-Point Designer。以 double 承载精确的二进制整数运算，显式模拟下列步骤；对位宽作断言，保证乘法及加减的整数中间量不超过double的精确整数范围。

| 阶段 | 位宽 / 小数位 | 处理 |
|---|---|---|
| 输入 H_LS | signed18 / 14 | 双训练平均或MID估计后量化 |
| 旋转系数 | signed18 / 16 | 16种周期系数，小ROM |
| 预旋转结果 | signed18 / 14 | 复乘全精度合成后统一舍入 |
| FIR累加 | signed26 / 14 | 核 `[1,6,15,20,15,6,1]`，保留DC空位 |
| 归一化倒数 | signed18 / 16 | 按有效权重和查表，边缘/DC特殊处理 |
| 归一化结果 | signed18 / 14 | 乘倒数后舍入、饱和 |
| 逆旋转输出 H | signed18 / 14 | 全精度复乘后舍入、饱和 |

范围采用二补码非对称范围。例如18/14为 [-8, 8-2^-14]。舍入为最近值，半LSB远离零；舍入后饱和。负数不能简单使用“加半LSB后算术右移”替代该规则。

`fir_channel_fixed` 返回五阶段的饱和分量数，`rx.channelSaturations` 累加本帧已执行的信道更新。若帧头提前失败，后续MID未执行，计数不包含那些阶段；它不是全链溢出统计。

二补码整数参考由独立的标量7点循环、整数乘法与右移舍入实现，未复用生产函数的 `conv` 和量化函数。另有纯Python整数验证导出向量，交叉核对RTL所需位序与数值结果。

### 本轮仍保留浮点的部分

- ADC/AGC、相关分数、CFO/NCO、FFT、LS输入生成；
- 噪声方差与FIR误差方差估计、可靠性权重和LLR生成；
- 导频相关累加、幅值/相角、抛物线插值及最终数据相位旋转。

导频只量化9×8搜索系数ROM，不是完整导频处理链定点。FIR方差仍采用原有噪声传播近似，不含滤波偏差、ISI/ICI和定点误差，因此还需要联合LLR校准。

## 4. 位宽与 AGC 的关系

新增 `run_fixed_precision` 对相同输入比较12/8、16/12、18/14三种数据格式，同时配套12/10、16/14、18/16系数及20、24、26位累加器。

误差指标是相对浮点FIR输出的NMSE，**不是信道估计本身相对真实信道的NMSE**，也不是译码门限差。输入尺度为0.001时，12/8产生0dB误差：即使没有饱和，精度也可能不足以保留有效信号。18/14在同条件下约-28.37dB，尺度0.25下约-75.72dB。

这支持把18/14保留为当前验证格式，但不证明全系统必须采用18位。最终应结合AGC输出范围、FFT缩放、深衰落和灵敏度门限选择位宽，避免只看正常增益下的高SNR测试。

## 5. 7020 存储与算术实现

窗口调整不增加复乘、FFT或相关次数；FIR核心仍为每次最多400次复旋转和约1800次复加减，9点导频搜索仍为2232次复MAC/帧。实际定点系数从此前预算的16位/分量改为18位，必须相应更新ROM容量：

| 对象 | 当前导出布局的容量 |
|---|---:|
| 16个复旋转系数 | 576 bit |
| 201个归一化系数 | 3618 bit |
| 9×8个复导频搜索系数 | 2592 bit |
| FIR六个复延迟寄存器，18位/分量 | 216 bit |

归一化输出有效频点的权重和仅有42、49、57、58、63、64六种，可将倒数数据压缩为108bit，再加地址选择逻辑；当前导出保留完整201点网格以便核对。完整窗口除64是移位，无需通用除法器。误差方差系数和数据缓存不含在以上表中。

18×18实乘可匹配DSP48E1乘法器输入宽度，但复乘通常需要多次实乘或多个DSP，不能把400次复旋转等同于400个DSP或直接断言一个DSP足够。

FIR软件用26位累加便于留保护位。由于输入已经限制为18位且正系数和为64，未饱和累加结果实际上可用24位表示；确认此不变量后，归一化实乘可使用24×18位，适配25×18乘法器。若改核、动态缩放或累加顺序，须重新证明，不能任意截断26位数据。

上述只是容量与算术映射依据，尚无RTL、综合、时序或功耗结果。原有LTF搜索和LDPC仍需完整周期调度，不能根据局部FIR省资源推断整链持续吞吐。

## 6. 测试与向量入口

在项目根目录 MATLAB 中：

```matlab
addpath('matlab'); addpath('matlab/tests');
run_demo('compact_fixed');
run_fixed_tests();
run_fixed_precision('matlab/results/fixed_precision.csv');
export_receiver_vectors();
receiver_budget();
```

导出位置：`matlab/vectors/receiver_fixed/`。包含FIR输入/预期输出、旋转ROM、归一化ROM、导频ROM及JSON格式说明。输入输出CSV保存有符号十进制整数；不是浮点值，解读需除以对应的2^小数位。

```bash
python3 matlab/tests/verify_receiver_vectors.py
```

完整实验结果见 [本轮验证记录](../results/FIXED_RECEIVER.md)。下一步优先补充路径检测可靠性、AGC/FFT缩放和LLR定点、SFO及分数时延信道；自组网所需的时间戳、时隙/收发切换、反馈与重传接口需要另行定义。
