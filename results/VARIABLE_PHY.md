# 可变长度 PHY v2 验证记录

后续已完成更大样本的门限、理想参数诊断与纯噪声检查，见 [接收灵敏度评估](SENSITIVITY.md)。本文保留最初的功能验证和20帧冒烟结果，不用它替代后续统计。

日期：2026-09-28。环境：MATLAB R2020b，`/opt/Polyspace/R2020b/bin/matlab`。v2是独立选择的实验空口格式；本记录不代表已经实现MAC/IP、自组网或FPGA。

## 功能与回归

已执行以下入口：

```matlab
addpath('matlab'); addpath('matlab/tests');
run_tests();
run_variable_tests();
run_variable_demo(1500);
run_receiver_tests(); run_compact_tests(); run_fixed_tests();
run_variable_sweep([36 644 1500],[4 6 8],20,'matlab/results/variable_smoke.csv');
export_vectors('/tmp/cofdm_v1_regression_vectors');
```

- 原有基础、接收算法、低复杂度及局部定点测试全部通过。
- 卷积码独立脉冲约定及30组软错误Viterbi恢复通过；9组种子/MID组合恢复通过。
- 具有正确CRC但版本、MCS、长度、种子、MID或保留位非法的头被拒绝；错误CRC、零/NaN/错误数量LLR被拒绝。接收长度上限512时，合法1500字节头被拒绝。
- 穷举1～2048字节的码字、填充、符号布局；非法长度被拒绝。
- 端到端长度为1、36、37、76、77、80、81、319、320、644、645、1499、1500、1514、1518、1536、2048字节，全部恢复正确。接收端每包使用未知长度的初始配置，发送端变换扰码种子和三种MID间隔；交替使用浮点/量化LDPC。
- 上述变长功能测试使用24dB、交替±135kHz CFO、37采样偏移、静态[0,3,9]采样多径，路径增益[1,0.25j,-0.12]；随机种子20261008。
- 有效头后截断载荷、破坏头、破坏数据、伪造有效CRC的4095字节超长头均被拒绝。
- 1500字节演示在20dB、135kHz CFO下通过；默认MID周期8，38码字、65数据符号、8MID，槽长1437.5μs。
- 重新生成的v1七个CSV及manifest与原参考文件逐字节相同，包括TX IQ，证明这些参考输入下v1发送结果未改变。
- 修正一处多余逗号后，全目录MATLAB Code Analyzer报告0条消息。

## 小样本性能扫描

原始数据：[variable_smoke.csv](variable_smoke.csv)。接收模式compact、浮点LDPC、MID周期8、载荷扰码种子93。固定随机种子20261009；每格20帧，静态多径时延[0,3,9]，增益[1,0.25exp(0.6j),0.12exp(-1j)]，CFO135kHz，初始偏移37采样。SNR为时域采样信噪比，不是Eb/N0。

成功载荷率按有效PHY载荷位数×成功比例/固定槽长计算，尚未扣除MAC头、信道接入、ACK、TDD换向或重传时间。因此不是实际IP吞吐。1500字节指整个PHY载荷；若承载1500字节IP包，还须加上MAC等开销再计算帧长。

0/20不是零误码保证：独立同分布假设下，其失败概率单侧95%上界约13.9%。该扫描只用于冒烟验证，没有与v1进行相同IQ/信道条件的配对性能比较，不能证明短头比原4符号LDPC头可靠。

## 定型前还需完成

1. 扩大样本并扫描更低SNR，以头失败率、同步漏检/虚警、载荷PER和成功吞吐分别评价。
2. 目前108个编码位按载波顺序映射，其余84位为扰码填充，未用于额外纠错。比较利用这些位置重复发送编码位并合并LLR，以及跨频率交织；它们是后续候选，尚未实现。
3. 比较一符号头与更强保护头在深频率衰落、干扰、SFO、时变信道下的可靠性；必要时保留鲁棒profile。
4. 冻结Viterbi度量位宽、LLR饱和、ACS并行度，综合7020资源/时序；同时验证变长LDPC持续吞吐和缓冲边界。当前没有RTL结果。
5. 加入连续多帧流式捕获、头后接收超时、TUN与无线MAC，验证真正的IP包和多节点组网。
