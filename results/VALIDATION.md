# 本次实际验证记录

日期：2026-09-23。主要环境：`/opt/Polyspace/R2020b/bin/matlab`（R2020b），未调用Communications Toolbox；GNU Octave 6.4.0也完成前期功能验证。此文件记录实际结果，不代表目标距离/空口认证/FPGA综合通过。

## 1. 功能回归

最终MATLAB版本9组测试全部通过，覆盖：

- 帧长度、有效载波、交织双射、码字装帧和资源数量检查；
- PRBS127周期、字节位序、CRC16/32单bit错误检测；
- QC编码器与独立GF(2)消元参考一致，10组随机信息和软bit扰动恢复；
- 量化LDPC的译码恢复、9位/2小数位后验范围及量化网格；
- STF16点重复、双LTF低互相关检查；
- 无噪声、20dB AWGN+135kHz CFO、22dB静态多径-220kHz CFO、20dB量化译码+65kHz CFO；
- 静默、纯噪声、单音、短capture拒绝和帧头损坏拒绝。

上述四个端到端正例的CFO误差依次约0、9.6、109.6、33.0Hz；起点误差≤1样本，payload逐字节匹配，CRC通过。

全部MATLAB源文件通过R2020b Code Analyzer检查，提示数为0。

`run_demo`示例采用静态[0,3,9]样本多径、22dB、135kHz频偏、37样本前置偏移。MATLAB估计CFO约135006.7Hz，帧起点38（MATLAB从1计数），载荷CRC通过，平均/最大LDPC轮数1/1。高SNR一轮通过不是硬件最坏时延证据。

`snr_smoke.csv`：每点20帧，静态[0,3,9]样本多径、135kHz CFO、37样本偏移、STF门限0.40、浮点LDPC。随机种子20260923，各SNR点使用连续随机流。

8dB时条件payload BER=0而PER非零并不矛盾：模型还要求所有码字syndrome通过，可能信息位已正确但校验位尚未收敛。当前采取保守失败判定。

20帧不足以给出可靠PER门限。0/20错误的95%单边上限仍约13.9%，不能宣称12dB时PER小于1%。低SNR的瓶颈已经从单纯捕获转移到估计/译码链，需要进一步对照完美CSI、无MID噪声和纯AWGN，但这些诊断不能作为实际接收机输入。

## 4. FPGA 向量

`vectors/generated/`由MATLAB导出确定性payload（字节0…255循环）和seq=1：

- 10560对TX IQ，signed16、14小数位，0个饱和分量；
- 16×648载荷码字位、648帧头码字位（帧头扰码前）；
- 12×24 QC移位矩阵、384点零基交织映射；
- 200载波的两个复数ZC训练序列；
- `manifest.txt`明确位序、缩放、移位方向和各列定义。

`sha256.json`记录本次导出的CSV/TXT文件哈希，便于后续RTL仿真确认向量版本。

该确定性帧的原采样率PAPR约9.230dB，尚未过采样/PA验证。`run_demo`使用随机payload，PAPR约9.75dB，不能要求两者一致。
